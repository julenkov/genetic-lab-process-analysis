# Словарь данных (синтетические данные)

Все данные сгенерированы скриптом `scripts/generate_event_log.py` (seed = 42) и не содержат реальной информации.

## event_log.csv: журнал событий (одна строка = одно выполненное действие)

| Поле | Описание |
| --- | --- |
| case_id | Идентификатор случая (один образец / одно исследование) |
| activity | Название действия |
| start_time | Начало действия |
| end_time | Окончание действия |
| resource | Исполнитель или оборудование |
| study_type | Тип исследования: «Панель генов» или «Экзом» |
| priority | «Плановый» или «Срочный» |

Время ожидания перед действием = start_time текущего действия − end_time предыдущего действия в том же случае.

## cases.csv: одна строка на случай

| Поле | Описание |
| --- | --- |
| case_id, study_type, priority | как выше |
| received_at | Когда получен образец |
| finished_at | Конец последнего действия |
| status | «Выдан результат» или «Отменён» |
| tat_days | Срок от получения образца до последнего действия, в днях |
| sample_reject, dna_redo, library_redo, reseq, report_rework | 1, если в случае был соответствующий повтор или брак |
