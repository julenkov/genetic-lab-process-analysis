# Регламент формирования партий секвенирования и контроля качества библиотеки

| Параметр | Значение |
| --- | --- |
| Код документа | РГ-ЛАБ-01 (условный) |
| Версия | 1.0 (проект) |
| Владелец процесса | Руководитель лаборатории |
| Статус | Учебный документ. Описывает процесс TO-BE ([diagrams/to_be.bpmn](../diagrams/to_be.bpmn)). Числовые значения условные и должны быть уточнены пилотом на реальной лаборатории |

## 1. Цель

Установить единые правила постановки образцов в партии секвенирования, чтобы сократить ожидание партии и долю повторных секвенирований.

## 2. Область применения

Правила действуют для образцов (панели генов и экзомы) от момента готовности библиотеки до получения и проверки данных секвенирования. Приём образцов и интерпретация вариантов регламентом не охватываются.

## 3. Термины

| Термин | Значение |
| --- | --- |
| Библиотека | Подготовленный из ДНК образца материал, готовый к секвенированию |
| Партия | Один запуск секвенатора, в который собраны несколько образцов |
| Окно приёма в партию | Время, до которого образец должен быть готов, чтобы попасть в партию |
| Срочный образец | Образец с отметкой «срочный» в направлении |
| Пересеквенирование | Повторное секвенирование образца после брака данных |

## 4. Роли и ответственность

| Роль | Ответственность |
| --- | --- |
| Лаборант | Проверка качества библиотеки, постановка в партию, записи в журналах |
| Биоинформатик | Проверка качества данных секвенирования, решение о пересеквенировании |
| Руководитель лаборатории | Утверждение расписания партий, решения по неполной загрузке и повторному браку |
| Менеджер по качеству | Контроль показателей (раздел 8), внесение изменений в регламент |

## 5. Расписание партий

| Тип образцов | Дни запуска | Старт | Закрытие окна приёма |
| --- | --- | --- | --- |
| Плановые | Понедельник, среда, пятница | 09:00 | 18:00 последнего рабочего дня перед партией |
| Срочные | Каждый рабочий день | 09:00 | 18:00 последнего рабочего дня перед партией |

Расписание утверждает руководитель лаборатории. Изменение расписания оформляется новой версией регламента.

## 6. Порядок работы

| № | Шаг | Исполнитель | Описание | Срок | Запись |
| --- | --- | --- | --- | --- | --- |
| 1 | Подготовить библиотеку | Лаборант | Подготовка по методике | По графику лаборатории | Журнал подготовки |
| 2 | Проверить качество библиотеки | Лаборант | Проверка по критериям методики (концентрация, размер фрагментов) | В тот же рабочий день, что шаг 1 | Журнал контроля качества |
| 3 | Принять решение по библиотеке | Лаборант | Годна: перейти к шагу 4. Не годна: выполнить «Повторить подготовку библиотеки» и вернуться к шагу 4. | В тот же рабочий день | Журнал контроля качества |
| 4 | Поставить в партию | Лаборант | Внести образец в журнал ближайшей партии с открытым окном приёма. Срочные ставятся в ближайшую дневную партию | Не позднее закрытия окна | Журнал партий |
| 5 | Ждать старта партии | Лаборант | Образец ожидает запуска по расписанию (раздел 5) | До старта партии | |
| 6 | Выполнить секвенирование | Лаборант | Запуск партии, контроль хода запуска | По расписанию | Журнал партий |
| 7 | Проверить качество данных | Биоинформатик | Данные годны: передать на биоинформатический анализ. Не годны: направить образец на пересеквенирование | В рабочие часы после завершения запуска | Журнал повторов |
| 8 | Пересеквенировать | Лаборант | Образец включается в ближайшую партию по расписанию с приоритетом, руководитель лаборатории уведомляется | Ближайшая партия | Журнал повторов |

Если библиотека не прошла проверку качества повторно, лаборант сообщает руководителю лаборатории, который решает, запрашивать ли новый образец.

## 7. Управление рисками

**Неполная загрузка партии.** Частые партии могут запускаться с неполной загрузкой, что повышает стоимость одного образца. Если в плановой партии образцов меньше установленного минимума, решение принимает руководитель лаборатории: запустить партию или перенести образцы на следующую. Минимум загрузки определяется руководителем исходя из ёмкости секвенатора (условно 50%). Образцы переносятся не более одного раза. Срочные образцы всегда запускаются в свою партию.

**Пик нагрузки на врачей-генетиков.** Результаты партий поступают к врачам в определённые дни. Руководитель клинического отдела планирует смены врачей с учётом дней запуска партий.

## 8. Показатели и контроль

Показатели оцениваются ежемесячно менеджером по качеству. Целевые значения получены на синтетической модели ([analysis/scenario_results.md](../analysis/scenario_results.md)), сценарии S2 и S6), в реальной лаборатории их нужно уточнить пилотом.

| Показатель | Было (AS-IS) | Цель (TO-BE) |
| --- | --- | --- |
| Среднее ожидание партии | 4,3 дня | не более 1,7 дня |
| Среднее ожидание врача-генетика | 1,8 дня | не более 0,9 дня |
| Средний срок от приёма до результата | 13,3 дня | не более 10,2 дня |
| Доля пересеквенирований | 4,1% | не более 1,7% |
| Загрузка партии | не измерялась | не ниже установленного минимума |

## 9. Записи

Журнал подготовки, журнал контроля качества библиотек, журнал партий, журнал повторов. Форма и срок хранения устанавливаются политикой лаборатории.
