# Чек-лист: постановка образца в партию секвенирования

Исполнитель: лаборант. Приложение к регламенту РГ-ЛАБ-01.

- [ ] Номер образца и маркировка совпадают с записью в журнале
- [ ] Подготовка библиотеки выполнена, запись в журнале подготовки внесена
- [ ] Качество библиотеки проверено, результат записан (годна или не годна)
- [ ] Если библиотека не годна: назначена повторная подготовка
- [ ] Если повторная подготовка не прошла проверку: руководитель лаборатории уведомлён
- [ ] Тип образца (плановый или срочный) указан верно
- [ ] Образец успевает в окно приёма: готов до 18:00 последнего рабочего дня перед партией
- [ ] Образец внесён в журнал ближайшей партии (плановые: пн, ср, пт; срочные: ближайший рабочий день)
- [ ] Для пересеквенирования отмечено «повтор», образец поставлен в ближайшую партию с приоритетом
- [ ] Загрузка партии проверена, при неполной загрузке получено решение руководителя лаборатории
- [ ] Исполнитель и время записаны в журнал партий
